CHAPTER 01 • 2017

The Genesis: Writing "Hello World" at Age 19

In 2017, at 19 years old, I sat before a terminal and typed my very first lines of code: echo "Hello, World!";. What started as pure curiosity quickly turned into an all-consuming passion for systems architecture, algorithmic thinking, and building tools that eliminate friction for other human beings.

I began in the bedrock of the web: pure PHP, raw relational MySQL databases, manual SQL normalization, and Apache servers. Crafting database schemas from scratch and writing custom query optimizers instilled a deep respect for foundational computer science principles that modern heavy frameworks often obscure.

FOUNDATIONAL LESSON
Understanding the Low-Level Before the Frameworks

Starting with raw SQL queries, session management, and procedural scripts meant understanding query execution plans, indexes, memory bounds, and socket handshakes. When moving to modern high-level abstraction frameworks, performance bottlenecks became immediately transparent rather than black boxes.

CHAPTER 03 • 2024

The Inception of jsonviewer.tools

Every software engineer spends hundreds of hours staring at unformatted, massive JSON API responses. Existing online viewers were slow, choked on large payloads, and displayed plain tree text without giving a bird's-eye architectural view.

In 2024, I engineered and launched jsonviewer.tools — an interactive graph visualizer that converts dense hierarchical JSON into connected visual node diagrams. It became the cornerstone of Visuo Labs, proving that developers hunger for visual, fast, zero-latency tooling.

WEB SAAS PLATFORM
jsonviewer.tools • Live Global Platform

Trusted daily by thousands of developers, data engineers, and API architects worldwide to inspect payloads, format schemas, and debug JSON visually.

CHAPTER 05 • ORGANIC DISCOVERY

Mastering SEO & Building for High Audiences

Early on, distribution was the hardest battle. Without millions in ad spend, how do you stand out among crowded stores and web search results?

I made a deliberate decision: never resort to low-quality spam or throwaway clones. Instead, I mastered programmatic SEO, Core Web Vitals optimization, semantic schema data, high-intent keyword targeting, and blazing fast page performance. When combined with real utility and zero latency, organic search engines reward genuine craft.

CORE PRINCIPLES OF DISTRIBUTION
The Visuo Labs Product Philosophy
  • ✓ Sub-100ms Interactions: Every tool must feel instantaneous with zero layout shift.
  • ✓ Privacy & Local-First: Keep user payloads on their local machine whenever feasible.
  • ✓ Aesthetic Delight: Sleek dark mode, crisp typography, and visual graph beauty.
  • ✓ Deep Multi-Platform Presence: Android, iOS, macOS, Windows, and Web simultaneously.
